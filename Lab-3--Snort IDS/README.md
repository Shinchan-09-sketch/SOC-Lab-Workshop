# Lab-03: Configuring, Monitoring and Analyzing Snort IDS Logs

## Aim

Configure Splunk Universal Forwarder on Ubuntu to collect Snort IDS alert logs and forward them to Splunk Enterprise running on Windows Server 2019.

---

## Step 1: Verify Snort Installation

Before configuring Splunk Universal Forwarder, verify that Snort is installed.

Open the terminal and execute the following command.

```bash
snort -V
```

The installed Snort version should be displayed.

---

## Step 2: Verify Snort Alert Log

Verify that the Snort alert log file exists.

```bash
ls -l /var/log/snort/
```

The directory should contain the alert log generated by Snort.

---

## Step 3: Configure Splunk Universal Forwarder

Navigate to the Splunk Universal Forwarder installation directory.

```bash
cd ~/splunkforwarder/bin
```

Add the Snort alert log for monitoring.

```bash
sudo ./splunk add monitor /var/log/snort/snort.alert.fast --sourcetype snort --index main --run-as-root
```

---

## Step 4: Configure Forward Server

Configure the Universal Forwarder to send logs to Splunk Enterprise.

```bash
sudo ./splunk add forward-server 192.168.184.134:9997 --run-as-root
```

---

## Step 5: Restart Splunk Universal Forwarder

Restart the Universal Forwarder to apply the configuration.

```bash
sudo ./splunk restart --run-as-root
```

---

## Step 6: Verify Forward Server

Verify that the forward server has been configured successfully.

```bash
sudo ./splunk list forward-server --run-as-root
```

The output should display the Splunk Enterprise server.

```
192.168.184.134:9997
```

---

## Step 7: Generate Snort Alerts

Generate network traffic or run test packets to trigger Snort alerts.

Confirm that new events are added to the Snort alert log.

```bash
tail -f /var/log/snort/snort.alert.fast
```

---

## Step 8: Verify Snort Logs in Splunk

Open Splunk Enterprise.

Navigate to **Search & Reporting**.

Search for Snort logs.

```spl
sourcetype=snort
```

or

```spl
source="/var/log/snort/snort.alert.fast"
```

If events are displayed, Snort IDS alerts are successfully forwarded to Splunk Enterprise.

---

## Result

Successfully configured Splunk Universal Forwarder to collect Snort IDS alerts from Ubuntu and forward them to Splunk Enterprise running on Windows Server 2019.
